**GreenScore** is an enterprise-grade **Sustainability OS** that transforms personal environmental tracking into a comprehensive, multi-tiered ecosystem spanning **IoT Smart Home Automation**, **University Campus Rankings**, **Corporate ESG Reporting**, **Municipal City Dashboards**, **Cryptographic Carbon Credit NFT Ledgers**, **2030 Climate AI Simulators**, **Spatial Thermal AR Heatmaps**, **Developer API Sandboxes**, **Voice AI Command Centers**, and **Dual Light/Dark Theme Styling**.

## ✨ Full 15 Feature Modules

### 🏠 1. Smart Home IoT Automation
- Real-time telemetry for Solar Edge 5kW Inverters, Living Room AC, Water Flow Meters, and EV Chargers.
- AI Smart Energy Nudges (+1°C thermostat shift cuts ~4.2 kWh/day).

### 🎓 2. University Campus Sustainability
- Departmental Leaderboard (CS #1: 91.2, Math #2: 87.5, Physics #3: 84.1, Electrical #4: 81.9, Civil #5: 79.4).
- Aggregated 142.5 MWh solar generation, paperless exam drives, and inter-faculty challenges.

### 🏢 3. Enterprise ESG Decarbonization
- GHG Protocol Scope 1 (Direct), Scope 2 (Electricity), and Scope 3 (Supply Chain) carbon accounting.
- Corporate department performance metrics and executive decarbonization insight.

### 🏙️ 4. Municipal Citywide Dashboard
- City Sustainability Index (78.4 / 100) monitoring energy grids, water conservation, waste recovery, and clean mobility.
- Real-time Air Quality Index (AQI 42 Good) and public EV fast-charging hub status (184 hubs).

### 📊 5. Automated ESG Reporting Engine
- GRI and ISSB framework compliant audit disclosure generator with JSON export options.

### 📡 6. Real-Time IoT Telemetry Stream
- Live MQTT / WebSocket stream simulation ingesting telemetry logs from physical ESP32 nodes (ACS712, YF-S201, HC-SR04, MQ-135).

### 🎁 7. Verified Rewards & GreenPoints
- Submit verified eco-actions (tree planting, electric transit) for GreenPoints (+15 Pts).
- Redeem rewards catalog (campus coffee passes, solar vouchers, carbon certificates).

### 🛍️ 8. Green Marketplace & Impact Calculator
- Eco products featuring embedded **Environmental Footprint Improvement Calculators** (+4.5 pts boost).

### 🧠 9. GreenScore AI Intelligence Layer
- **Conversational AI**: Instant recommendations on score improvement and energy saving.
- **Computer Vision Waste Classifier**: Scans waste images to classify recyclables and award points.
- **Predictive Forecasting**: 30-day energy draw and carbon footprint projections.

### 💎 10. Cryptographic Carbon Credit NFT Ledger
- Verra VCS & Gold Standard certified carbon credit minting with cryptographic audit hashes (`0x7f9a...`).

### 🔮 11. 2030 Climate Scenario AI Engine
- Interactive policy sliders (Renewable %, EV penetration %, Reforestation %) simulating 2030 Earth temperature anomalies and economic impacts.

### ⚔️ 12. Peer-to-Peer Eco Battle Arena
- Live sustainability duels (CS Dept vs Math Dept) and daily streak quests.

### 👁️ 13. AR Spatial Thermal Heatmap
- HTML5 spatial AR canvas visualizing AC cool air leaks, solar roof panel irradiance, and indoor AQI density.

### 📡 14. Developer API & Webhook Sandbox
- API key generator (`gs_live_...`), Swagger-like endpoint runner (`GET /v2/score`), and Webhook event simulator.

### 🎙️ 15. Voice AI Command Assistant
- Hands-free speech synthesis interface for controlling smart home IoT and accessing ESG metrics.

## 🎨 Dual Light & Dark Theme Support

GreenScore features a dynamic theme engine:
- **Dark Theme (Default)**: Deep Cyber Emerald & Glassmorphism UI (`--bg-dark: #080d14`).
- **Light Theme**: Fresh Mint & Soft Pure Light Mode (`--bg-dark: #f0fdf4`).
- Toggle seamlessly using the **Sun / Moon** icon in the header.

## 🚀 Quick Start

### Installation

```bash
# Clone the repository
git clone https://github.com/vijaymahes9080/GreenScore.git

# Navigate to directory
cd GreenScore

# Install dependencies
npm install

# Start local development server
npm run dev
```

Open `http://localhost:3000` in your browser.

### Building for Production

```bash
# Build optimized static bundle
npm run build

# Preview production build
npm run preview
```
