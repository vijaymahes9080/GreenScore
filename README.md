**GreenScore** is an enterprise-grade **Sustainability OS** that transforms personal environmental tracking into a comprehensive, multi-tiered ecosystem spanning **IoT Smart Home Automation**, **University Campus Rankings**, **Corporate ESG Reporting**, **Municipal City Dashboards**, **Cryptographic Carbon Credit NFT Ledgers**, **2030 Climate AI Simulators**, and **Spatial Thermal AR Heatmaps**.

## ✨ Key Features & Modules

### 🏠 1. Smart Home IoT Automation
- Real-time telemetry monitoring for Solar Edge 5kW Inverters, Living Room AC, Water Flow Meters, and EV Chargers.
- AI Smart Energy Nudges alerting users to power consumption anomalies (+1°C thermostat adjustment saves ~4.2 kWh/day).

### 🎓 2. University Campus Sustainability
- Departmental Leaderboard ranking CS, Math, Physics, Electrical, and Civil departments.
- Campus-wide solar generation, paperless exam drives, and inter-faculty eco challenges.

### 🏢 3. Enterprise ESG Decarbonization
- GHG Protocol Scope 1 (Direct), Scope 2 (Electricity), and Scope 3 (Supply Chain) carbon accounting.
- Corporate department performance metrics and executive decarbonization insight.

### 🏙️ 4. Municipal Citywide Dashboard
- City Sustainability Index (78.4 / 100) monitoring municipal energy grid, water conservation, waste recovery, and clean mobility.
- Real-time Air Quality Index (AQI 42) and public EV fast-charging hub status.

### 📊 5. Automated ESG Reporting Engine
- GRI and ISSB framework compliant audit disclosure generator with JSON/PDF export capabilities.

### 📡 6. Real-Time IoT Telemetry Stream
- Live MQTT / WebSocket stream simulation ingesting telemetry logs from physical ESP32 nodes (ACS712, YF-S201, HC-SR04, MQ-135).

### 🎁 7. Verified Rewards & GreenPoints
- Submit verified eco-actions (tree planting, electric transit) for GreenPoints.
- Redeem rewards catalog (campus coffee pass, solar accessory vouchers, carbon certificates).

### 🛍️ 8. Green Marketplace & Impact Calculator
- Eco products featuring embedded **Environmental Footprint Improvement Calculators** (+4.5 pts boost).

### 🧠 9. GreenScore AI Intelligence Layer
- **Conversational AI**: Instant answers on score improvement and carbon reduction.
- **Computer Vision Waste Classifier**: Scans waste images to classify recyclables and award points.
- **Predictive Forecasting**: 30-day energy draw and carbon footprint projections.

### 💎 10. Cryptographic Carbon Credit NFT Ledger
- Verra VCS & Gold Standard certified carbon credit minting with cryptographic audit hashes (`0x7f9a...`).

### 🔮 11. 2030 Climate Scenario AI Engine
- Interactive policy sliders (Renewable %, EV penetration %, Reforestation %) simulating 2030 Earth temperature anomalies and economic impacts.

### ⚔️ 12. Peer-to-Peer Eco Battle Arena
- Live sustainability duels and daily streak quests.

### 👁️ 13. AR Spatial Thermal Heatmap
- HTML5 spatial AR canvas visualizing AC cool air leaks, solar roof panel irradiance, and indoor AQI density.

### 📡 14. Developer API & Webhook Sandbox
- API key generator, Swagger-like endpoint runner, and Webhook event simulator.

### 🎙️ 15. Voice AI Command Assistant
- Hands-free speech synthesis interface for controlling smart home IoT and accessing ESG metrics.

## 🚀 Quick Start

### Prerequisites
- Node.js (v18+)
- npm or pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/vijaymahes9080/GreenScore.git

# Navigate to directory
cd GreenScore

# Install dependencies
npm install

# Start local development server
npm run dev
```

Open `http://localhost:3000` in your browser.

### Building for Production

```bash
# Build optimized static bundle
npm run build

# Preview production build
npm run preview
```
